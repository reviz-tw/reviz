把工作做透明，
把客戶當夥伴。

reviz 是一支由工程師、設計師與分析師組成的小型工作室，自 2018 年起在台北接案。我們相信好專案不是「交付」出來，是「一起做」出來的。

我們所有工具偏好開源，所有過程文件可被客戶隨時檢視，每個專案有公開的更新日誌與決策紀錄。能被檢查的東西才會被信任。

我們接 NT$50 萬到 NT$800 萬的案子，從兩週的設計衝刺到一年期的數位轉型陪跑都做。先聊聊你的題目，再決定要不要合作。

--open-source
預設開源
可釋出的工具與函式庫一律 GitHub 公開。
02
--open-data
資料公共化
經客戶同意的清理資料集附公開連結。
03
--open-process

04
--with-readers
與讀者共做
產品與內容歡迎讀者協作、回報、貢獻。
